# Spot Momentum Scanner

Приложение отслеживает рост малоликвидных торговых пар Bybit Spot с котировкой USDT и отправляет уведомления в Telegram. Linear Perpetual, RSI и EMA-сканирование полностью удалены.

## Правила мониторинга

- Используются только активные пары Bybit Spot с котировкой USDT.
- В обычный Watchlist входят пары с оборотом за последние 24 часа не выше 1 000 000 USDT.
- Пара, которая уже превышает лимит при первом появлении, исключается сразу.
- Если отслеживаемая пара пересекает лимит оборота вверх, она остаётся в Watchlist ещё 24 часа. Если оборот вернулся к лимиту или ниже, пара остаётся в обычном Watchlist. Если лимит всё ещё превышен после 24 часов, пара исключается.
- Сигнал возникает при росте цены строго более чем на 5% за скользящее 15-минутное окно. Проверка выполняется по обновлениям Spot ticker WebSocket, не дожидаясь закрытия свечи.
- Для одного непрерывного движения отправляется один сигнал. Повторная активация возможна после возврата роста к 5% или ниже.
- Для восстановления окна после старта используются последние закрытые одноминутные свечи Bybit. События сначала fsync-записываются в локальный JSONL spool, затем сохраняются в PostgreSQL и ставятся в очередь доставки.

## Telegram

Доступ защищён общим паролем. Команды:

- /start — включить уведомления о росте Spot-монет.
- /stop — отключить уведомления.
- /history — показать последние полученные сигналы роста.
- /clearhistory — запросить очистку личной истории; удаление выполняется только после подтверждения.
- /help — справка.

Очистка истории удаляет только историю и очередь доставок текущего пользователя. События, которые всё ещё нужны другим пользователям, сохраняются. Подписка и Watchlist не удаляются.

## Запуск

Скопируйте .env.example в .env, задайте POSTGRES_PASSWORD, а для Telegram — TELEGRAM_BOT_TOKEN и длинный TELEGRAM_ACCESS_PASSWORD.

Запустите: docker compose up -d --build

Проверка состояния: docker compose ps

Логи приложения: docker compose logs -f app

Остановка без удаления данных: docker compose down

Команда docker compose down -v удаляет PostgreSQL и локальный spool уведомлений.

## Переменные окружения

- BYBIT_REST_URL — Bybit REST API.
- BYBIT_PUBLIC_SPOT_WS_URL — Bybit Spot public WebSocket.
- SPOT_MARKET_REFRESH_INTERVAL — период обновления Spot-каталога и Watchlist.
- TELEGRAM_BOT_TOKEN — токен Telegram-бота.
- TELEGRAM_ACCESS_PASSWORD — общий пароль доступа.
- APP_DATA_DIR — каталог для надёжного локального spool.

## База данных

Миграции выполняются автоматически при старте. Миграция 000009_remove_rsi_scanner удаляет таблицы Linear/RSI-сканера, пользовательские параметры RSI и всю историю RSI-сигналов. Удалённые данные восстановить нельзя; down-миграция намеренно блокирует откат. Telegram-пользователи и Spot-таблицы сохраняются.
