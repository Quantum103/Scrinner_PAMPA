# Миграции базы данных

Файлы миграций располагаются непосредственно в этом каталоге.

Формат имени:

- `000001_description.up.sql` — применить изменение;
- `000001_description.down.sql` — отменить изменение.

У каждой миграции должны быть оба файла с одинаковым номером и именем. Номера должны быть уникальными и задавать порядок применения.

Миграции выполняются при запуске приложения в транзакции PostgreSQL. Для сериализации одновременного запуска нескольких экземпляров используется PostgreSQL advisory lock.

Реестр применённых миграций хранится в таблице `schema_migrations`. SQL-файлы не должны содержать команд управления транзакциями (`BEGIN`/`COMMIT`), поскольку транзакцией управляет приложение.
